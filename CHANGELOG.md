# Changelog

All notable changes to the "Pet Judge" extension will be documented in this file.

## [1.0.0] - 2026-05-02
- Initial release.
- Features:
  - Dog and Cat characters.
  - Automatic triggering on errors.
  - Customizable default character (Dog, Cat, or Random).
  - Dedicated **Random Mode** toggle in the sidebar UI.
  - Customizable auto-open behavior.
